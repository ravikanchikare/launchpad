# HarnezPad identity and application artwork

`HarnezPadNativeIcon.png`, `HarnezPadNative.icns`, `HarnezPadMenuBarNative.png`, and its
`@2x` variant are generated by `scripts/generate-macos-icons.sh`.

The generator draws a local vector matching the Hugeicons `TerminalIcon` used
by the shadcn Luma preset. It does not use SF Symbols. The menu-bar PNGs are
black template glyphs on transparency so AppKit can apply the active macOS
menu-bar appearance.

Provider and launcher artwork remains separate content imagery. The source SVGs
are canonical; `generate-provider-pngs.sh` creates the local `codex.png`,
`claude-code.png`, and `opencode.png` files consumed by the offline Vite bundle.
The React interface uses the preset's Hugeicons library for all interface icons.
